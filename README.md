# Mira Math AI - OpenAI MATH Competition Tutor & Solver 🧮🤖

> **Mira Math AI** is an advanced Android app and Web application designed for solving competition-level mathematical problems based on the landmark **OpenAI MATH dataset research paper** (*"Measuring Mathematical Problem Solving With the MATH Dataset"* by Hendrycks et al.).

---

## 🌟 Overview & Research Alignment

The **OpenAI MATH dataset** contains 12,500 challenging competition mathematics problems (AMC 10, AMC 12, AIME, USAMO) with step-by-step LaTeX solution derivations across 7 core subject categories and 5 difficulty levels:

1. **Algebra**
2. **Counting & Probability**
3. **Geometry**
4. **Intermediate Algebra**
5. **Number Theory**
6. **Prealgebra**
7. **Precalculus**

**Mira Math AI** brings this dataset and mathematical reasoning engine into a modern mobile & web interface, featuring client-side **KaTeX math rendering**, **Chain-of-Thought (CoT) step derivation**, an **interactive scientific LaTeX keyboard**, and a **Native Java Android Bridge**.

---

## 📱 Features

- ⚡ **Step-by-Step AI Problem Solver**: Enter LaTeX equations or plain text to derive rigorous mathematical solutions.
- 📐 **KaTeX Mathematical Typesetting**: High-performance, zero-latency LaTeX rendering for complex formulas and matrices.
- 🎯 **OpenAI MATH Benchmark Explorer**: Practice curated problems across all 7 subject disciplines and Levels 1 to 5.
- ⌨️ **Interactive Math Keyboard**: Build fractions, exponents, summations, integrals, and roots with quick-touch keys.
- 📱 **Native Android Integration**: Features hardware-accelerated WebView with tactile haptic feedback, native sharing, and clipboard integration.
- 🎨 **Dark / Light Glassmorphism UI**: Beautiful, responsive layout with HSL-tailored colors and smooth micro-animations.

## 🏗️ Building & Installation

### Android APK (`MiraMath.apk`)

`MiraMath.apk` is compiled using Android SDK Build-Tools 34, D8 DEX compiler, 4-byte ZipAlignment, and `apksigner` with V1, V2, and V3 signatures for universal compatibility (Android 7.0 - Android 15+).

Download the latest APK from [GitHub Releases](https://github.com/apravint/mira-math-android/releases/tag/v1.0.0).
